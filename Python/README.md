# Python Books

This folder is for learning Python in a simple, beginner-friendly way.

## Reading Order

1. `smarter_way_python.pdf`
   - Start here if you are new to Python.
   - Focus on syntax, variables, control flow, functions, and practical examples.

## Best Use

- Read one chapter at a time.
- Type the examples yourself.
- Build small scripts after each topic.
- Learn Python before starting deep learning books in `AI_BOOKS/`.
