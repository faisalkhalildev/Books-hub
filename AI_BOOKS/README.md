# AI Books

This folder is for artificial intelligence, machine learning, and deep learning resources.

## Recommended Preparation

Before starting AI books, you should be comfortable with:

- Basic programming logic.
- Python fundamentals.
- Functions, classes, lists, dictionaries, and file handling.
- Basic math comfort, especially algebra and arrays.

## Reading Order

1. `Deep_learninng/deeplearningwithpython.pdf`
   - Start here when you are ready to learn deep learning with Python.
   - Read slowly and practice with code examples.

## Professional Reader Note

AI books are easier when you treat them as engineering books, not only theory books. Run examples, inspect errors, change parameters, and keep notes about what each model is doing.
