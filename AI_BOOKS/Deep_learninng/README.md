# Deep Learning Books

## Overview

This collection offers a carefully curated path into deep learning, balancing theoretical foundations with practical, hands-on application. Whether you're training your first neural network or fine-tuning complex architectures, these resources are designed to build both your intuition and technical confidence.

## Recommended Reading Order

1. `deeplearningwithpython.pdf`
2. `Dive into Deep Learning.pdf`

## How to Use This Guide

- Start with a solid Python foundation before diving in — comfort with NumPy and basic ML concepts will go a long way.
- Work through the examples actively: run the code, modify it, and observe how changes affect outcomes.
- As you progress, keep notes on key topics such as:
  - Model architecture decisions
  - Dataset preparation and preprocessing techniques
  - Training strategies and hyperparameter tuning
  - Evaluation metrics and how to interpret them
  - Common failure modes and how to debug them

## Learning Mindset

Deep learning rewards curiosity and persistence. Reading builds understanding, but real mastery comes from experimentation — tweaking parameters, breaking things intentionally, and learning from what the model tells you. Approach each chapter as an invitation to explore, not just a lesson to complete.
