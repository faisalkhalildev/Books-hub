# MERN Stack Books

This folder is a practical learning path for frontend and MERN-stack developers. The books are organized by topic so you can move from web basics to JavaScript, React, Redux, and React Native in a clean order.

## Folder Order

1. `Html-and-Css-Books/`
2. `JavaScript-Books/`
3. `React-js-Books/`
4. `React-Native/`

## Recommended Reading Path

1. `Html-and-Css-Books/Wiley.HTML.and.CSS.Oct.2011.pdf`
   - Learn page structure, styling, layout, and frontend basics.

2. `JavaScript-Books/ASmarterWaytoLearnJavaScript.pdf`
   - Start here for JavaScript fundamentals and hands-on practice.

3. `JavaScript-Books/ECMAScript6.pdf`
   - Learn modern JavaScript syntax, modules, classes, promises, and cleaner patterns.

4. `JavaScript-Books/Javascript Complete Book in Urdu.pdf`
   - Use this when Urdu explanations help you understand JavaScript concepts more deeply.

5. `JavaScript-Books/Secrets of the JavaScript Ninja, Second Edition - 2016.pdf`
   - Read this after the basics for advanced JavaScript, architecture, and professional frontend thinking.

6. `React-js-Books/the-road-to-learn-react.pdf`
   - Move into React components, props, state, and real app structure.

7. `React-js-Books/redux-book.pdf`
   - Read after React when you need predictable state management.

8. `React-Native/React_Native_in_Action_v7_MEAP.pdf`
   - Use after React when you want to build mobile applications.

## How to Use This Folder

- Start with the earliest skill you do not already know.
- Build small projects while reading JavaScript and React books.
- Use the advanced JavaScript book as a reference after completing the beginner material.
- Keep React Native for later unless your immediate goal is mobile development.

## Professional Reader Note

This is a strong frontend engineering path. The order matters: HTML/CSS gives structure, JavaScript gives behavior, React gives application architecture, Redux gives state discipline, and React Native expands the same thinking to mobile apps.
